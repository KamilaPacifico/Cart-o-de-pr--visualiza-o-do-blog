## Meu processo

### Construído com

- HTML5 semântico
- CSS3 com variáveis, Flexbox e `transition`
- Fonte Figtree (Google Fonts)
- Nomes de classe no padrão BEM

### O que aprendi

- Usar variáveis CSS (`--yellow`, `--gray-950`) para não repetir cores.
- Criar os estados `:hover` e `:focus-visible` e por que o foco visível importa para quem navega só pelo teclado.
- Usar `max-width` com `width: 100%` para o cartão se adaptar a telas pequenas.
- Fazer sombra "dura" (sem desfoque) com `box-shadow`.
- Usar `border-radius: 50%` para deixar uma imagem redonda.
